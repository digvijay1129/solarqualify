# Generated Design Reference Map

The six generated UI references are included in this directory:

1. `references/01-homeowner-dashboard.png` — homeowner overview, metrics, project progress, activity and quick actions.
2. `references/02-lead-submission.png` — five-step solar installation inquiry and bill upload journey.
3. `references/03-project-status-tracking.png` — current project stage, milestone timeline, summary, next actions and updates.
4. `references/04-quotations.png` — quotation details, generation assumption, pricing pending states, subsidy caveat and homeowner actions.
5. `references/05-document-management.png` — categories, search/filter, document table and upload panel.
6. `references/06-profile-support.png` — homeowner profile/property data, preferences, FAQs and support form.

These images are visual specifications. They are not placed as screenshot backgrounds in the application; all UI elements are implemented as real React controls.
